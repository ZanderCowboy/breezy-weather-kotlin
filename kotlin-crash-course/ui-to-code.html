  • 🎨 Kotlin Code - Makes things interactive and loads data
  • 🖼️ Resources - Colors, icons, and text

The Journey: From User Tap to Code Execution

Let's follow what happens when you tap the "Refresh Weather" button:

1 User taps button - Your finger touches the screen
⬇️
2 Android detects touch - System registers the tap event
⬇️
3 Button's onClick triggered - Your Kotlin function gets called
⬇️
4 ViewModel gets notified - Business logic starts executing
⬇️
5 Repository fetches data - Weather API gets called
⬇️
6 UI updates - New weather data appears on screen

File Structure: Where to Find Things

When you want to modify something you see, here's where to look in the BreezyWeather codebase:

📁 app/src/main/
📁 java/org/breezyweather/
📁 ui/ ← UI Controllers (Activities, Fragments)
📁 main/
📄 MainActivity.kt ← Main screen controller
📄 MainActivityViewModel.kt ← Business logic & state
📁 fragments/
📄 HomeFragment.kt ← Home screen UI logic
📁 search/
📄 SearchActivity.kt ← Search screen
📁 settings/
📄 SettingsActivity.kt ← Settings screen
📁 common/extensions/ ← Helper functions
📁 res/ ← Resources (layouts, images, colors)
📁 layout/ ← XML layout files
📄 activity_main.xml ← Main screen layout
📄 fragment_home.xml ← Home fragment layout
📄 item_weather_card.xml ← Weather card layout
📁 values/
📄 colors.xml ← App colors
📄 strings.xml ← Text content
📄 styles.xml ← UI styling
📁 drawable/ ← Icons and images

🎯 Quick Navigation Rules:

  • See a button? → Look in res/layout/ for the XML, then the corresponding Activity/Fragment
  • Want to change colors? → res/values/colors.xml
  • Need to modify text? → res/values/strings.xml
  • Button not working? → Check the Activity's onClick method
  • Data not loading? → Look in the ViewModel and Repository

// In HomeFragment.kt
fun updateTemperature(weather: Weather) {
    val temp = weather.current?.temperature?.temperature
    binding.temperatureText.text = "${temp?.toInt()}°C"
}

// Data comes from Weather data class
data class Temperature(
    val temperature: Double?
)

🔄 Refresh Button

What you see: A button that updates weather when tapped

What happens when tapped:

  1. Button click detected
  2. ViewModel called
  3. Weather repository fetches data
  4. UI updates with new data
// In activity_main.xml
<Button
    android:id="@+id/refreshButton"
    android:text="Refresh Weather"
    android:onClick="onRefreshClicked" />

// In MainActivity.kt
fun onRefreshClicked(view: View) {
    viewModel.refreshWeather() // Calls ViewModel
}

// In MainActivityViewModel.kt
fun refreshWeather() {
    viewModelScope.launch {
        val weather = repository.getCurrentWeather()
        _weatherData.value = weather // Updates UI
    }
}

Debugging: When Things Don't Work

🔍 Common Issues & Where to Look:

❌ Button doesn't respond to clicks

Check:

  • Is android:onClick set in XML?
  • Does the function exist in the Activity?
  • Is the button enabled? (android:enabled="true")
⚠️ Data not showing up

Check:

  • Is the ViewModel updating the LiveData/StateFlow?
  • Is the UI observing the data changes?
  • Is the Repository actually fetching data?
✅ UI looks wrong

Check:

  • Layout XML files for positioning
  • styles.xml for styling
  • colors.xml for color definitions

Pro Tips for Android Development

🎯 Essential Development Workflow:

  1. Design the UI → Create/modify XML layout files
  2. Add interactions → Write Kotlin click handlers
  3. Connect data → Use ViewModels and LiveData/StateFlow
  4. Test on device → Run app and interact with real UI
  5. Debug issues → Use Android Studio debugger and logs

🛠️ Development Tools

  • Layout Inspector: See live UI hierarchy
  • Logcat: Debug print statements
  • Debugger: Step through code execution
  • Device preview: Test different screen sizes

🎨 UI Modification Tips

  • Small changes: Modify XML attributes
  • New elements: Add views to layout files
  • Styling: Use themes and styles
  • Dynamic content: Update via Kotlin code
